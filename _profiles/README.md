# Tool Outputs (the evidence the agent actually saw)

Generated by `src/tools/profile.py` and `src/tools/invariants.py`, and pasted
verbatim into the agent's prompt by `run_agent_v2.sh`.

Layout: `_profiles/<SCALE>/<case_id>/` contains three files.

- `day1.json` - statistical profile of the reference feed
- `day2.json` - statistical profile of the candidate feed
- `invariants.json` - cross-column invariants discovered in day1, re-tested on day2

`S` is 200-row files, `L` is 50,000-row files. Compare a matching pair to see
the point of the design: **the profiles are the same size at both scales**,
which is why token cost is flat while the direct-prompt baseline is rejected
at 50k rows.

Together with `_raw/` (unedited API responses) and `traces/` (session
transcripts), these make the full pipeline auditable without running anything:
evidence in, reasoning, verdict out.
